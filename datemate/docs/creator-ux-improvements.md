# 발견·선택·공유 UX 개선

1. 첫 진입: /api/inspirations에서 실제 서울 카탈로그의 출처 있는 장소를 반경2.5km에서 연결해 예시를 보여준다. '등록된 실제 장소 아이디어·일정 계산 전'이라고 표시한다. 선택하면 지역/활동을 입력하고 원래 날짜/예산은 보존한다. 기존 하단 테마 카드도 숨겨진 퀵빌더 대신 같은 입력 흐름으로 연결했다. 인기·최신 순위나 영업 확인을 주장하지 않는다.
2. 사진: 제목의 공간/메뉴 단서로 사진의 성격을 표시하고 공간 관련 제목을 먼저 배치한다. 실제 촬영 공간을 검수했다는 표현은 하지 않는다. 사진 선택 버튼, 없는 경우 장소명·분류·주소가 있는 빈 상태 카드와 검색/재시도를 제공한다.
3. 설명: 실제 요청 활동과 후보의 일치 수, 실내·실외 확인 수, 이동 시간을 결정 요약에 제공한다. 모호한 감성·소음·인기를 생성하지 않는다.
4. 비교: 옵션의 실제 활동별 장소 수로 이름을 만들고 이동 우선 옵션에는 이동시간을 붙인다. 옵션 버튼/비교표/지도/공유 카드가 같은 이름을 사용한다. 구성이 같으면 다르다고 꾸미지 않으며 기존 중복 억제와 한계 안내를 유지한다.
5. 후기: 검색 API에서 받은 description을 작성일과 함께 화면에 발췌한다. 본문 전체/방문 인증이 아니라는 표시를 유지한다. 가격·주소·이유와 함께 앱 안에서 확인하고 원문은 필요할 때 연다.
6. 공유: 외부 사진 없이 canvas로1080x1350 PNG를 만든다. 코스명, 날짜, 인원, 시간표, 장소, 예상비용/이동 및 미확인 비용 안내를 포함한다. 미리보기/다운로드/요약 복사, 파일 공유 지원 기기에서는 네이티브 공유를 제공한다. 서버 업로드 없음. 인쇄/PDF는 기존 유지.

## 검증
전체 자동 테스트196개 통과. 실제 브라우저에서 예시→조건 적용→실제 추천, 개인화 이유, 옵션 이름, 후기 요약3개, PNG 파일 서명/1080x1350 크기, 모바일390px 가로 넘침 없음, JS 오류 없음, 사진 선택 및 사진없는 상태를 확인했다. 다운로드는 임시 폴더에서 실제 저장 후 검사했다. 운영체제별 공유 대상 앱은 이 환경에서 검증하지 않았으며 지원하는 브라우저에서만 버튼을 표시한다. 실사용자 만족도 수치를 주장하지 않는다.

자동 검사: scripts/check_creator_ux_ui.py. 사용자 요청에 따라 수정 후 테스트·실제 화면·실패 동작 확인을 필수로 수행하도록 상위 PROJECT_NOTES.md에 기록했다.
