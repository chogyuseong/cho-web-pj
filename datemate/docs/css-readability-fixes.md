# CSS 겹침·가독성 점검 (2026-10-23)

확인한 문제 및 수정:
- 스크롤 시 sticky 옵션 탭이 코스 카드 본문을 덮음: 결과 옵션 탭을 일반 문서 흐름으로 변경. 오른쪽 지도 고정은 유지.
- 과거 테마의 좁은 모바일 시간표: 600px 이하에서 시간/번호를 카드 상단 한 줄로 배치. 절대 배치 번호와 세로선 제거, 동작 버튼 줄바꿈.
- 상세 제목과 버튼의 공간 경쟁: flex wrap 및 모바일 버튼 2열, 긴 글자 줄바꿈.
- 사진 위 문구 배경과 보조 문구 대비: 어두운 캡션 배경, 라벨과 지도 출발 마커 색 보정.
- 작은 보조 글자/조건 라벨: 주요 영역 14~15px 이상으로 조정. 긴 옵션 경로를 잘라내지 않고 줄바꿈.
- 팝업: 동적 화면 높이에 맞춘 최대 높이, 내부 스크롤, 닫기 버튼 공간 및 버튼 줄바꿈.

검증:
- check_css_readability.py: 홈/추천/펼친 레저/공유 팝업 텍스트 색과 조상 배경색을 합성해 대비 검사. 결과 docs/css-contrast-audit.json. 320/390/768/1024/1440px 가로 넘침 없음, JS 오류 없음.
- check_editorial_design.py: 홈/저장 결과 320/390/768/1440px 통과.
- check_leisure_results_ui.py: 선택/한 방문지만 교체/되돌리기/배치 통과.
- check_creator_ux_ui.py: 실제 추천/후기 3건/카드 PNG 저장/모바일 통과.
- check_explore_500_ui.py: 장소 목록·더 보기·상세·검색·빈 결과 통과.
- check_photo_carousel_ui.py: 사진 좌우·순환·키보드·스와이프·실패 복구 통과.

자동 대비 검사는 이미지·그라데이션·외부 지도 전체의 시각적 접근성을 보장하지 않는다. 발견된 색/배치 충돌을 수정한 범위이며 전체 접근성 인증이나 실제 iOS/Android 기기 테스트는 아니다.
