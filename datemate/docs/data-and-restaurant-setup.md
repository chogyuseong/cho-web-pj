# 식사 추천과 데이터 확인

코스 상세에서 방문 장소 사이마다 공식 가이드에 소개된 식당을 최대 3곳 추천합니다. 현재 식당 14곳은 미쉐린·한국관광공사·강남구 공식 관광 안내의 사실 정보를 요약하고 네이버 Maps로 주소 좌표를 확인했습니다. 추천 이유의 출처는 각 식당 카드에서 열 수 있습니다. 동선에서 직선 기준 3km 이내이고 추가 이동이 5km 이하인 식당만 표시합니다. 원래 코스의 방문 수·시간·비용은 바꾸지 않으며 식사 비용·소요시간·대기는 별도입니다.

## 직접 필요한 설정

실제 테스트 결과 현재 검색 키의 **지역 API는 HTTP 401**이며 응답 메시지는 “요청한 API가 이 Application에서 활성화되어 있지 않습니다.”입니다. 이미지·블로그는 작동하므로 키 값 자체 문제는 아닙니다.

네이버 클라우드 콘솔 → Application Services → NAVER API HUB → Application → 현재 앱 수정 → **NAVER 검색의 ‘지역’ API**를 추가해 주세요. 기존 키를 바꿀 필요는 없습니다. 콘솔에서 적용한 뒤 식당 카드의 ‘주변 식당 더 찾기’를 다시 누르면 서버 재시작 없이 사용합니다. 자동 대량 호출은 하지 않으며 사용자가 눌렀을 때만 검색하고, 구간별 결과를 1시간 캐시합니다.

공식 설정 안내: https://guide.ncloud-docs.com/docs/apihub-application

지역 API는 업체명·주소·분류·좌표를 제공하지만 **메뉴 가격·영업시간·예약 잔여석을 제공하지 않습니다.** 이 권한 추가만으로 모든 운영정보가 채워지지는 않습니다. 대기·실시간 예약은 매장·예약 서비스에서 직접 확인해야 하며, 지금 단계에서 별도의 유료 API나 다른 키를 추가할 필요는 없습니다.

## 줄인 미확인 항목

운영기관·공식 관광 안내에서 확인한 8곳의 시간·입장료·예약 여부 등 확인 가능한 항목을 `data/operating_facts.json`에 근거 URL·확인일·적용 범위와 함께 보강했습니다. 무료 상설전시를 유료 특별전까지 무료로 취급하지 않습니다. 야간 개장·주간 운영시간은 지원되는 범위에서 요일별로 계산하며 특정일 임시 운영은 보장하지 않습니다.

작은 인원 수의 계산 반영, 사용자 설정 체류 시간, 사용자가 허용한 이동 추정, MBTI 보조 선호는 별도 확인이 필요한 운영사실과 구분합니다. 단체 입장·예약 필요 여부·입장료·영업정보 등 실제로 비어 있는 데이터는 그대로 남기고 ‘방문 전 확인’ 안에 모았습니다. 단순히 미확인을 충족으로 바꾸지 않습니다.

`scripts/check_meals_and_facts_ui.py`로 코스 사이 식당 3개, 블로그 원문 링크, 공식 확인 자료, 추정값 상태 및 JavaScript 오류 없음을 확인합니다. 예시 기본 코스의 미확인 종류는 3개(가격·예약·운영정보)이며, 장소에 따라 달라집니다.
