# 데이트 코스 분류

대분류를 선택하면 해당 소분류를 표시합니다. 소분류는 한 개를 선택하며 ‘전체’는 분류 제한을 적용하지 않습니다. 대분류 변경 시 이전 소분류 선택을 초기화합니다.

| 대분류 | 소분류 |
| --- | --- |
| 계절별 | 봄, 여름, 가을, 겨울 |
| 날씨별 | 맑은 날, 비 오는 날, 눈 오는 날 |
| 콘셉트별 | 즐거운 데이트, 편안한 데이트, 지적인 데이트, 동심 데이트 |
| 타입별 | 활동적인, 사교적인 |

콘셉트·타입은 요청한 명칭입니다. 계절·날씨 소분류는 기본 구성으로 추가했습니다. 서버의 app/taxonomy.py에서 항목과 기존 장소 유형 연결을 관리합니다.

선택값은 Conditions의 date_category/date_subcategory에 보존되어 일정 생성·교체에 적용됩니다. 기존 장소 유형은 데이터 호환을 위해 유지합니다. 잘못된 대분류·소분류 조합은 거절합니다. 비·눈 오는 날은 실내 장소만 찾습니다. 계절은 장소 유형을 고르는 서비스 분류 규칙이며, 실제 예보·개화·단풍·시즌 운영이나 성격을 검증한 결과가 아닙니다.

검증: 전체 테스트 48개 통과. 실제 브라우저에서 대분류 4개, 소분류 전체 목록, 분류 변경 시 초기화, API 전달, 지적인 데이트 추천 및 390px 가로 넘침 없음을 확인했습니다.
