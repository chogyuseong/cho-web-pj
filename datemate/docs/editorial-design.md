# 2026 디자인 개편

방향: 큰 타이포그래피, 실제 도시 사진, 블루 포인트와 따뜻한 바탕, 여백 중심의 편집형 구성. 색·레이아웃·컴포넌트 상태를 static/editorial.css 마지막 시각 레이어에서 통합한다. 기존 기능 ID와 상태 동작은 유지한다.

- 첫 화면: 두 칼럼 제목/서울 사진, 코스 생성과 아이디어 보기 CTA.
- 실제 장소 아이디어: 저채도 블루/코랄/올리브 카드, 명확한 번호와 정보 구분.
- 폼: 필드 그룹별 구분선과 넉넉한 입력 높이, 추가 설정 분리 유지.
- 결과: 선택 옵션 강조, 비용·조건·타임라인·지도 위계 정리, 정보 카드와 버튼 상태 통일.
- 모바일: 헤더/사진/옵션 카드 재배치.320px에서는 날짜·시간을 한 열로 표시. 사진 미리보기는 세로 카드.
- 접근성: 키보드 포커스,44px 이상 주요 입력/버튼, reduced-motion 대응. 기존 사용자 요청의 검색 회전 표시 유지.

참고(2026-10-23 확인): https://www.figma.com/resource-library/web-design-trends/ , https://webflow.com/blog/web-design-trends-2026 . 동향을 참고한 디자인 선택이며 전환율 향상이나 사용자 선호가 입증됐다는 주장은 하지 않는다.

검증: 자동196개 통과. check_editorial_design.py로 홈/결과320,390,768,1440px 가로넘침/JS오류 검사 및 실제 스크린샷 시각 확인. check_creator_ux_ui.py로 실제 추천, 후기3개, 사진 전환, 빈 사진상태,PNG다운로드/1080x1350, 모바일 화면 검사. 프리뷰는 docs/design-preview/.
