# 전체 기능·코드 점검 — 2026-10-26

## 판단

검증한 핵심 기능은 아래 범위에서 통과했다. 추가로 재현한 제품 오류 4개와 Linux 테스트 설정 오류 1개를 수정했다. 모든 외부 기능의 정상 동작을 보장하는 상태는 아니다. 실제 메뉴 조회는 HTTP 403으로 실패하며, 생성형 AI·의미 임베딩은 키 미설정으로 실호출 검증이 불가능했다.

## 발견 및 수정한 오류

1. **다른 모달에 늦은 교체 후보가 섞임**: 교체 후보를 요청한 뒤 다른 상세창을 열면 이전 응답이 같은 DOM에 후보를 추가했다. 모달 세대·열림 상태·원래 일정 ID를 검증하고, 교체 버튼에서도 현재 일정을 확인하도록 수정했다. 교체 완료 응답이 이후 선택한 코스를 강제로 덮지 않도록 처리했다.
2. **코스 카드 요약의 링크를 상대방이 열 수 없음**: 소유자 전용 `/?plan=...` 주소를 복사했다. 요약 복사 시 전용 24시간 공유 토큰을 만들고 `/shared#...`를 복사하도록 수정했다. 다른 세션에서 조회 가능하고 철회 후 404가 되는지 검증했다.
3. **후기 삭제 후 신고가 남음**: 후기 행만 지워 연결된 신고 행이 고아 기록으로 남았다. 신고와 후기를 같은 트랜잭션에서 삭제한다. 신고 등록도 존재 확인과 삽입을 같은 쓰기 잠금 아래 실행해 삭제와의 경쟁을 방지한다.
4. **개인정보 삭제 후 질문 호출량 기록이 남음**: `recommendations:<owner>`만 지우고 `chat:<owner>`는 지우지 않았다. 질문 기록도 삭제하고 다른 사용자의 한도 기록을 유지하는지 검증했다.
5. **Linux CI에서 일부 브라우저 검사 실행 불가**: 이미지·지도 테스트 하나가 `msedge`로 고정되어 CI의 Chromium 설정을 무시했다. 공통 환경 설정을 사용하도록 수정했고 Linux Chromium 전체 검사로 확인했다.

처음 4개는 수정 전 재현 검사에서 **4 failed**를 확인했다. 수정 후 새 검사와 전체 회귀 검사가 통과했다. Linux 문제는 기존의 고정 채널 설정과 CI 설정을 대조한 뒤 실제 Linux 전체 실행으로 수정 결과를 확인했다.

## 코드 검토 결과와 운영 한계

- 추천 API와 백그라운드 작업은 공통 서비스를 호출하며, 실행 제한·필수 조건 검사·최종 저장 전 취소 확인을 유지한다.
- DB 변경은 순차·트랜잭션 방식이다. 삭제 이후 쓰기 차단, 공유용 명시적 필드 목록, 세션별 일정 접근 제한을 확인했다.
- 요청 크기·전송 시간·동일 출처 변경 요청·호스트·쿠키·캐시·오류 헤더를 검사했다. 이것이 전문 침투 테스트나 모든 취약점 부재를 증명하는 것은 아니다.
- 공개 메뉴 원문은 현재 HTTP 403이다. UI가 실패 안내를 제공해도 실제 메뉴 기능이 성공한 것으로 볼 수 없다. 안정적인 정보 공급원 확보가 별도 필요하다.
- 실제 장소 목록 수집에서 565개의 검색을 처리했다. 기본 공급자 호출 한도 600회/시간을 사용하는 경우 초기 전체 수집만으로 대부분의 한도를 사용할 수 있다. 이미지·블로그·추천 호출도 같은 호스트의 한도를 공유하므로 예상 사용량에 맞는 운영 한도와 수집 정책을 검토해야 한다. 한도를 무조건 올리지는 않았다.
- PostgreSQL의 전체 쓰기 잠금과 웹 프로세스 내부 추천 작업은 소규모 운영을 위한 기존 절충이다. 다수 사용자 부하, 긴 작업의 서버 종료, 실제 운영 비용은 별도 평가 대상이다.
- 생성형 AI 키가 없어 실제 모델 답변·의미 임베딩 품질과 비용은 미검증이다. 기본 해시 임베딩을 의미 이해 모델로 평가하면 안 된다.
- 실제 Google Cloud Run/Cloud SQL의 IAM·도메인·HTTPS·백업 복원·장애 전환과 실물 iOS/Android·Safari는 검증하지 않았다. 브라우저의 모바일 화면 크기 검사는 실물 기기 검사와 다르다.
- 원격 GitHub Actions는 실행하지 않았으나, 이번에는 로컬 Linux 컨테이너에서 Chromium과 PostgreSQL로 전체 테스트를 실행했다.
