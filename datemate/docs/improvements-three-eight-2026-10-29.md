## 동작 원칙

- 추천 조건·제외 요청과 필수 조건을 개인화보다 우선한다.
- 시연 모드의 피드백은 실제 장소 모드에 섞지 않는다.
- 운영 자료의 확인일과 검색으로 업체를 찾은 시각은 다르다.
- 메뉴·운영 파일을 가져와도 실제 업체 정체성이나 이용 권리를 자동 인증한 것은 아니다.
- API 키가 없거나 응답이 잘못되면 실제 경로 확인으로 표시하지 않는다.
- 지연 로딩 사진/메뉴, SDK 재시도, DB·호스팅 등은 추천 내 HTTP 비용 추정과 분리한다.
- 기존 사용자 환경 파일과 데이터를 자동으로 바꾸거나 외부 리소스를 배포하지 않는다.

실행 방법은 [운영 인수인계](operations-handoff.md)에 정리했다.
