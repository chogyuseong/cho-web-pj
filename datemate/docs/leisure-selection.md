# 레저 선택 위치 수정 (2026-10-23)
- 앞선 4번 선호 입력의 레저 종목 선택 UI를 제거했다. 종목별 검색 해석은 유지한다.
- 결과창 각 방문 장소 아래 '이 동선에서 즐길 레저 골라보기'에서 현재 장소 반경 1.5km의 실제 스포츠 후보를 조회한다(펼칠 때 조회).
- 사용자가 장소를 선택하면 해당 순서만 교체. 다른 방문지는 유지하고 시간·비용·지도/요약을 다시 계산한다. 코스 카드 저장 등 기존 기능 사용 가능.
- 직선 거리·시간/비용 변화 표시. 고정 장소, 타 사용자 일정, 알 수 없는 장소 선택은 서버에서도 거절한다. 교체 되돌리기 지원.
- 실제 후보 검색은 네이버 지역 API의 반환 범위에 한정된다. 주변 모든 업소의 완전한 목록을 보장하지 않는다. 후보 없음/오류/재검색 안내 제공.
- 검증: tests/test_leisure_results.py + test_leisure_intent.py + test_api.py 7개 통과. 모바일 390px에서 실제 로컬 API/데모 코스로 후보 펼침→한 장소만 교체→다른 방문지 유지→되돌리기 통과, JS 오류/가로 넘침 없음. 실시간 업체 영업/예약 여부 검증과는 별개.
