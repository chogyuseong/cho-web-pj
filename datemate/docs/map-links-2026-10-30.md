# 지도 링크 검색어·직접 연결 개선 — 2026-10-30

## 원인과 변경

- 기존에는 `업체명 + 전체 도로명 주소` 또는 `업체명 + region`을 각 화면에서 따로 만들었다. 주소를 붙인 문자열 전체에 도로명 정규식을 적용하면서 업체명 속 `종로3가`를 `종로3`으로 잘라낼 수 있었다.
- 지도 검색 기본값을 **서울 + 구 이름 + 정확한 업체명(지점명 포함)**으로 통일했다. 층·호수·건물명·도로명 숫자를 지도 검색어에 붙이지 않는다. 지역 정보가 없으면 서울+업체명을 쓴다. 메뉴·이미지 검색용 `업체명 + 건물 번호까지의 주소`는 별도 함수로 유지한다.
- 업체명과 주소를 분리해서 처리하고, 도로 번호 뒤가 `가` 같은 글자로 이어지면 도로 번호로 오인하지 않는다. 서울·구 이름으로 시작하는 이미 정리된 지도 검색어에서 업체명을 삭제하지 않는다.
- 레저/식당/지도 우측 목록/팝업/일정 링크/장소 상세에 공통 `placeMapLink` 적용.
- 상호·주소·좌표로 검증된 네이버 업체 ID가 확보되면 `/p/entry/place/ID`로 직접 연결한다. ID를 내부 장소 ID에서 추측하지 않고 `naver_place_id_verified`를 확인한다. 사진 응답으로 검증 ID를 받았을 때 이미 화면에 있는 지도 링크도 갱신한다. 사진 캐시는 v6로 분리했다.

## 실제 검색어 비교

[비교 결과 JSON](map-query-audit-2026-10-30.json): 클라이밍파크 종로점, 박흥권탁구클럽, 코델, SAAN 2, 대한민국역사박물관 5곳. 지역 검색 API의 업체 좌표로 같은 업체인지 대조했다.

| 조합 | 같은 업체가 1순위인 표본 |
|---|---:|
| 업체명 + 건물 번호까지의 주소 | 4/5 |
| 업체명만 | 3/5 |
| 서울 + 업체명 | 4/5 |
| 서울 + 구 + 업체명 | 5/5 |

이 표본 결과는 모든 서울 업체의 최적 검색어를 증명하지 않는다. 지역 검색 API와 네이버 지도 웹의 검색 순위도 동일하다고 가정하지 않는다. 실제 네이버 지도 브라우저에서는 새 검색어 페이지 HTTP200 및 검색창에 정확한 검색어가 입력된 것을 확인했다. 외부 지도 결과 전체를 자동 검증했다는 뜻은 아니다.
