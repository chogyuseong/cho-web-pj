# 모바일 동작 점검 (2026-10-23)

환경: 로컬 http://127.0.0.1:8000, Edge/Chromium headless. 실제 휴대폰이나 iOS Safari 테스트는 아님.

통과:
- 홈/저장 코스 결과 화면 320,390,768,1440px 가로 넘침 및 JS 오류 없음.

- 390px 모바일/터치에서 서울 장소 500건 중 24→48개 더 보기, 장소 상세 대화상자, 중구 검색, 검색 결과 없음 처리 통과.
- 사진 좌우/순환/키보드 및 합성 touch 이벤트의 스와이프, 이미지 실패 시 기존 이미지 유지 통과.
- 모바일 탐색 전환/새로고침 복원/코스 입력 복귀 통과.
- 필수 입력/상세 옵션, 추천→조건 수정→재추천, 모바일 가로 넘침 없음 통과.

범위 밖: 실기기 터치·가상 키보드·Safari 파일 저장·모바일 통신망·실제 네이버 지도 타일/인증/경로 정확성. 지도 검사는 옵션 상태 동기화이며 외부 지도 전체 기능 정상 보증이 아님.
