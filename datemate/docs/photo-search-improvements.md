# 사진 검색 개선

장소명 전체가 연속해서 제목에 있어야 했던 조건을 개선했다. 이름/지점의 모든 단어를 유지하면서 순서·구두점·중간 단어 차이를 허용한다. 한국어 위키백과로 연결된 이름을 검색 별칭으로 사용하고, 첫 검색에서 일치 사진이 없으면 구 이름을 포함해 한 번 더 검색한다. 검색 후보는 10개에서 30개로 확대하고 최종 사진은 최대5개다. 이미지 조회는 별도 3개 동시 실행으로 블로그 검색 대기와 분리했다.

라이선스가 없는 검색 결과는 계속 검색 참고 이미지로 표시하며 사용 조건 확인 완료라고 주장하지 않는다. 장소가 다른 이미지를 임의로 붙이거나 대체 사진으로 채우지 않는다. 없는 사진의 안내는 키 미설정/연결 실패/일치 검색 없음으로 구분하고 외부 검색 링크를 제공한다.

최근 추천 장소7곳의 동일 표본을 비교했다. 기존6/7곳에서 개선 후7/7곳에 검색 결과가 있었다. 라망 시크레는0→5장. SAAN2와 라망 시크레의 실제 브라우저 이미지 naturalWidth>0을 검사했다. 이는 모든 업체나 모든 원본 서버의 표시를 보장하는 수치가 아니다. 원본 핫링크 제한이나 삭제 시 다른 후보/검색 원문을 사용한다.

재현: scripts/check_photo_coverage_after.py, scripts/check_saan_photo_ui.py, scripts/check_lamain_photo_ui.py. 보고서 photo-audit-before.json/photo-audit-after.json. 빈 주소·지점 구분·제목 어순·추가 지역 검색 회귀 테스트 포함.
