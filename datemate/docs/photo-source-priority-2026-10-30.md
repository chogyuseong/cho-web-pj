# 사진 출처 우선순위 및 관계없는 사진 제외 — 2026-10-30

## 원인

이전 화면은 이미지 검색 결과의 제목에 업체명이 있으면 사용했다. 같은 후기의 음식·이동·다른 방문지 사진도 글 제목을 공유할 수 있어 사진 내용과 업체의 관계를 보장하지 못했다.

## 적용 기준

1. 상호·서울 주소·좌표로 유일하게 연결한 업체에서 **업체 등록 표지가 명시된 사진**을 먼저 사용한다. CDN 도메인이나 대표 사진이라는 이유만으로 사장님 업로드라고 추정하지 않는다.
2. 확인된 업체 ID의 공개 업체 사진 탭도 조회한다. 자료 안의 업체 ID·좌표와 등록 주체를 다시 대조한다. 401/403/429에서는 재시도·우회 없이 쉬며 Retry-After를 존중한다.
3. 업체 사진을 확보하지 못하면 장소 검수 사진 또는 해당 업체 레코드에 직접 연결된 후기·공개 사진을 사용한다. 등록 주체가 불분명한 사진은 그렇게 표시한다.
4. 이후 블로그 후기 사진은 해당 업체·지점 이름이 **사진 설명 또는 바로 앞 문구**에 명시된 것만 사용한다. 글 전체에 업체명이 있다는 이유로 모든 사진을 가져오지 않는다. 본문 밖 로고, 다른 지점, 중복 URL, 레저 후기의 식사·커피·셀카 설명 사진을 제외한다.
5. 관련성을 확인할 수 없으면 사진이 없다는 안내를 표시한다. 업체 사진이 한 장만 확인되면 같은 업체로 확인된 공개·후기 사진으로 부족분을 보충한다. 불명확한 사진으로 두 장을 채우지 않는다.

기존 이미지 검색 함수의 제목 필터를 갤러리 기본 공급자로 사용하던 경로를 제거했다. 일반 장소·식당·레저 카드가 공통 media API에서 이 기준을 사용한다. 출처 링크에는 업체 등록/방문자 후기/블로그/등록 주체 미확인을 구분해 표시한다. 기존 공개 사진 캐시는 v4로 분리하고 블로그 사진도 별도 캐시한다.

## 추가 사진 수집 보완

대표 사진 한 장에서 검색이 끝나던 처리와 한 공급자에서 사진이 있으면 다음 공급자를 생략하던 처리를 변경했다. 부족하면 다음 주소·사진 검색을 계속하고, 동일 업체 공개/블로그 자료를 보충한다. visitorImages/photos/photoList 및 업체 ID가 연결된 별도 사진 레코드도 읽는다. 썸네일·원본·리사이즈 URL은 같은 사진으로 묶는다. 화면도 공개 사진 한 장만 받은 경우 보충 조회한다. 공개 사진 캐시는 v5로 분리했다.

- 관련 데이터/사진 검사 23 passed, 후속 PC·모바일/추가조회/교체/지도/가독성 13 passed(67.34초). 중복 검사는 합산하지 않는다.
- 실제 클라이밍 파크 종로점: 기존 1장 → 사진 후보 5장(3.33초). 실제 외부 이미지를 로드하는 모바일 Edge에서 서로 다른 사진 2장 표시·스크립트 오류 없음 확인. 테스트 브라우저에 샘플 데이터를 전달하고 실제 CDN 이미지를 로드했으며 사용자 DB에는 테스트 일정을 저장하지 않았다.
- 제공처 제한 등으로 추가 자동 조회가 실패할 때는 사진이 없다고 단정하지 않고 자동으로 불러오지 못했음을 안내한다.
- 최신 서버 PID25020/8000. 환경 파일 변경 없음.


## 사진 실패 시 리뷰 직접 조회

- `/media?fallback=reviews` 경로 추가. 기존 업체 사진 조회·캐시를 반복하지 않고 리뷰 사진을 직접 반환한다. 일반 장소 갤러리와 레저 2장 갤러리의 표시 실패 대체 경로를 이 API로 연결했다. 레저의 최초 사진 조회 실패도 리뷰 조회를 시도한다.
- 업체·지점명이 일치하는 단독 후기에서는 사진마다 업체명을 반복하지 않아도 본문 사진을 사용할 수 있게 했다. 여러 장소를 묶은 코스/투어 글은 이 완화를 적용하지 않는다. 다른 지점과 문맥상 음식/셀카, 본문 밖 이미지·프로필·스티커는 제외한다. 이는 이미지 픽셀 내용의 자동 인증은 아니다.
- 리뷰 사진의 리사이즈 URL 중복도 제외하고, 이전 빈 결과 캐시를 v3로 분리했다.
- 관련 검사29 passed(35.95초), 후속 리뷰 API/사진16 passed(28.24초). 중복 합산하지 않는다. 깨진 업체 사진2장→리뷰사진2장 자동 대체를 브라우저로 검증했다.
- 실제 클라이밍 파크 종로점 리뷰 사진5장 확보. 업체 사진이 빈 상태를 테스트 브라우저에 전달해 리뷰 자동 요청1회/실제 CDN 이미지2장 표시/JS오류0 확인. 사용자 DB에 테스트 일정을 저장하지 않았다.
- 최신 서버 PID21392/8000. `.env` 변경 없음. 제공처가 리뷰 본문·이미지까지 차단하거나 사진이 없는 경우에는 원문 링크와 재시도 안내를 유지한다.
