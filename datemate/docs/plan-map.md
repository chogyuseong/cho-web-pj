# 일정 상세 네이버 지도

일정 상세의 출발·방문 번호·귀가를 네이버 지도 마커로 표시하고 전체 위치가 보이도록 화면 범위를 맞춥니다. 등록된 웹 주소인 `http://localhost:8000`에서 실제 지도와 마커 4개(출발, 1, 2, 3)의 표시를 확인했습니다. 테스트용 8011 주소에서는 지도 인증이 실패했으므로 실제 접속 주소와 Dynamic Map 웹 서비스 URL 설정을 일치시켜야 합니다.

- 실제 모드·자동차: Directions 응답의 [경도, 위도] path를 받아 실선으로 표시합니다. 경로 없는 기존 일정은 점선이므로 새로 추천해야 합니다.
- 데모 또는 도보·대중교통·자전거: 점선은 방문 순서를 보여주는 직선 연결입니다. 실제 도로·보행·대중교통 경로로 표시하지 않습니다. 구간별 네이버 앱 길찾기 링크를 유지합니다.
- 가상 장소는 실제 지도 위에 표시해도 방문 가능한 장소가 되지 않으며 데모임을 안내합니다.
- 지도 키 누락·로딩·인증 실패 시 개략도와 외부 링크로 대체합니다. 서버 비밀키는 브라우저에 전달하지 않습니다.
- 실제 장소의 운영정보 부족으로 추천이 보류되는 정책은 유지합니다. API 키 입력만으로 운영정보가 채워지지는 않습니다.

검증: 전체 테스트 33개 통과, JavaScript 구문 검사 통과. 입력된 서버 키로 서울시청→광화문 실제 자동차 API 응답과 path 43개를 확인했습니다. localhost:8000에서 Edge 데스크톱 지도·마커 및 모바일 가로 넘침 없음을 확인했습니다. 실제 모드의 완성된 일정 전체를 검증한 것은 아닙니다.

브라우저 재검증: 서버 실행 후 PowerShell에서 `$env:DATEMATE_TEST_URL='http://localhost:8000'` 설정 후 `python scripts/check_plan_map.py` 실행.

공식 구현 참고: https://navermaps.github.io/maps.js.ncp/docs/naver.maps.Polyline.html
