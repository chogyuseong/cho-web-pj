# 읽기 쉽고 선택하기 명확한 화면

기존 크림·코랄 분위기를 유지하면서 정보 크기, 대비, 선택 상태와 조작 영역을 정리했다.

- 본문 16~18px, 핵심 안내 14px 이상, 입력 17px을 기준으로 통일했다.
- 모바일에서 일정 버튼이 10px로 줄어들던 강제 규칙을 제거했다.
- 필수 입력 세 그룹에 ‘필수’를 표시하고 선택 항목은 별도로 유지했다.
- 옵션을 ‘코스 1·2·3’으로 통일하고 현재 코스에는 ‘선택됨’ 표시와 테두리를 추가했다.
- 비용 비교 표의 ‘예상 전체 비용’, ‘총 이동 시간’, ‘장소 차이’ 의미를 명확하게 했다.
- 표에 키보드 초점과 스크롤 설명을 추가했다. 표 내부 가로 스크롤은 허용하고 페이지 가로 넘침은 방지했다.
- 주요 버튼 높이를 44px 이상으로 맞추고 작은 화면에서는 채팅 입력과 전송을 두 줄로 배치했다.
- 키보드 이용자를 위한 ‘본문으로 바로가기’를 추가했다.
- 방문 준비 영역의 불필요한 세로 여백을 줄였다.

공통 기준은 `static/readability.css`, 방문 준비 구성은 `static/execution-summary.css`에서 관리한다.
