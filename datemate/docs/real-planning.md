# 실제 장소 코스 사용

## 전체 조건 대조

`app/condition_audit.py`에서 대안 여부와 관계없이 추천 결과·교체 결과·기존 저장 플랜을 원래 입력과 대조합니다. 지역, 출발지, 방문 날짜와 영업·휴무·입장·휴게시간, 시작·종료, 인원, 예산, 교통수단과 경로, 방문 수, 테마·데이트 분류·계절·날씨, 테마 구성, 실내외, 제외 활동, 예약, 구간 이동·총 도보, 귀가, 체류, 추정 허용, MBTI, 자유 요청, 고정 장소를 검사하거나 정보 한계를 표시합니다.

`condition_checks`에는 충족·추정 기준 충족·불일치·미확인·참고 상태를 기록하며, 불일치·미확인 항목 전체는 `deviations`로 카드와 상세 화면에 표시합니다. ‘전체 조건 확인’을 펼치면 나머지 검사 결과도 확인할 수 있습니다. 운영정보·수용 인원·예약 잔여석·실제 교통·계절 상태·예보·MBTI 취향·자유 요청 전체 의미 등 확인하지 못한 사항을 충족으로 바꾸지 않습니다.

검증 화면: `docs/screenshots/all-conditions.png`. 검사 결과: `docs/all-conditions-check.json`. `python scripts/check_all_conditions_ui.py`로 여러 조건 동시 불일치, 미확인 정보, 기존 저장 플랜의 새 검사, 화면의 전체 검사 목록을 검증합니다.

## 조건에 가까운 대안

모든 조건을 만족하는 결과가 없으면 빈 화면 대신 조건에 가까운 코스를 최대 3개 제안합니다. 기존 조건으로 검증한 결과가 있으면 그 결과를 우선합니다. 대안은 테마·실내외·예약·구간 이동·종료 시각·총 도보·예산·방문 수의 차이를 가중 점수로 비교한 제한된 탐색 결과입니다. 최적해를 보장하지 않습니다.

원래 입력 조건은 결과에 그대로 저장합니다. 카드와 상세 화면에 조건별 차이 및 이동·시간·비용 초과량을 표시하고, 장소 교체 시에도 다시 계산합니다. 피할 활동과 고정 장소는 유지하고, 확인된 휴무·마감시간을 위반한 방문은 제안하지 않습니다. 미확인 영업정보나 비용을 충족 또는 무료로 바꾸지 않습니다. 추정 비허용 요청에 참고 코스를 제시할 경우에도 추정 사용 사실을 별도로 표시합니다.

검증: `python -m pytest -q` 79개 통과. `python scripts/check_best_effort_ui.py`에서 강동구 카페 및 30분 일정 요청에 대안 3개, 초과 안내, 원래 입력값 보존, 사진 로드, JavaScript 오류 없음을 확인했습니다.

기본 화면은 실제 서울 장소 모드입니다. 주소 검색 또는 지도에서 출발지를 선택하고 날짜, 시간, 인원, 테마, 방문 수, 이동 제한을 설정한 뒤 추천합니다. 자유 입력은 추천 시 규칙으로 해석하며, 해석 결과는 폼에 표시합니다. 날짜·출발지·교통 등 해석하지 못한 사항은 폼에서 직접 선택해야 합니다.

Wikidata 문화·산책 장소에 더해 공식 안내에서 확인한 카페·놀이·공예·휴식 장소 8곳을 보강했습니다. 하이커 그라운드는 기존 Wikidata 장소를 갱신하여 같은 시설이 코스에 중복되지 않게 합니다. 보강한 장소의 주소·분류·근거는 `data/curated_place_sources.json`, 지오코딩 좌표와 사진 검색 키워드는 `data/curated_places.json`에 있습니다. 복수 테마를 가진 장소는 해당 활동 모두로 검색하며 실내·실외 필터도 적용합니다. 아직 보강된 장소는 종로·중구 중심이며, 조건을 자동 완화하거나 다른 지역 장소를 끼워 넣지 않습니다. 기존 키의 NAVER API HUB 지역 검색 권한은 HTTP 401이므로 임의의 주변 업체를 실시간 검색하는 기능은 없습니다.

‘이동·체류 시간을 추정한 실제 장소 코스 받기’를 선택하면 실제 좌표와 사용자 체류 시간으로 코스를 계산합니다. 이동 시간은 직선거리 × 1.35와 교통수단별 가정 속도를 사용합니다. 실제 도로 경로, 시간표, 정체 또는 미래 교통 예측이 아닙니다. 네이버 앱 길찾기에서 실제 이동을 확인해야 합니다.

운영시간·휴무·가격·예약 미확인 상태는 원본 카탈로그에 그대로 유지하며 결과의 미확인 항목으로 표시합니다. 알려지지 않은 가격을 무료로 간주하지 않습니다. 합계·잔여 예산은 알려진 비용만으로 계산하므로 총예산 충족을 보장하지 않습니다. 추정 비허용 요청에서 검증 가능한 코스가 없으면 추정 사용 사실을 표시한 대안을 제공합니다.

사진은 장소별 네이버 이미지 검색과 Wikimedia 보조 검색을 사용합니다. 브라우저에서 로드에 실패하면 다음 검색 사진을 시도합니다. 검색 사진은 장소 실물이나 이용 권리를 검수한 이미지가 아니며 출처 링크를 함께 제공합니다. 가상 장소에는 실제 사진을 붙이지 않습니다.

검증: `python -m pytest -q` 79개 통과. `python scripts/check_recommendation_matrix.py`로 모든 소분류 13개, 자유 입력, 교통수단·방문 수 변경 등 18개 조합에서 실제 추천 버튼 동작을 확인합니다. 놀이·카페·비 오는 날 코스 각각 3곳의 사진 로드와 JavaScript 오류 없음을 확인했습니다. 결과는 `docs/recommendation-matrix.json`, 화면은 `docs/screenshots/matrix-*.png`에 기록합니다.
