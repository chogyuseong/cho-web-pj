# 디자인 레퍼런스 선정 및 적용 (2026-10-23)

## 선정
주요 참고: Lapa Ninja의 Paris by Emily, 보조 참고: Raus.
- https://www.lapa.ninja/post/parisbyemily/
- https://www.lapa.ninja/post/raus/
- 여행 분야 비교 목록: https://www.lapa.ninja/category/outdoors-travel/

선정 이유는 사용자 인터뷰로 검증한 결과가 아니라, 현재 서비스의 핵심 행동(장소 발견 → 취향 입력 → 코스 비교)에 대한 제품 판단이다. 도시 체험을 골라보는 여행 서비스가 기업 홍보나 포트폴리오보다 작업 목적에 가깝다. Paris by Emily 실제 페이지의 시각 화면도 브라우저로 확인했다. 움직이는 도입 화면은 우리 서비스에 적용하지 않았다.

## 비교 범위
- GDWEB https://gdweb.co.kr/ : 국내 여행/레저 선정 사례와 분류 확인. 롯데호텔 실제 사이트는 접근 제한 화면이라 세부 화면을 확인했다고 주장하지 않는다.
- CSS Design Awards https://www.cssdesignawards.com/ : UI/UX/Innovation 평가 및 실험적 사례 확인. 이번에는 강한 영상/3D보다 즉시 입력 가능한 정적인 구성에 우선순위를 둔다.
- Lapa Ninja : 여행 분야 목록과 위 두 사례의 서비스 설명/분류 확인. 이 중 도시 체험 서비스 방향 선정.
- Awwwards 여행 목록은 도구 접속 시간 초과로 세부 비교에서 제외. Behance 사례를 직접 검토했다고 주장하지 않는다.

## 독립 구현
- 코랄색 핵심 버튼, 크림 배경, 짙은 본문 색상으로 기존 editorial.css의 팔레트 변경.
- 새로운 한국어 문구, 비대칭 서울 사진 영역, 직접 작성한 SVG 점선과 이용 단계 메모 카드.
- 도입 → 장소 아이디어 → 필수 조건 입력 → 코스 비교로 연결. 레퍼런스의 레이아웃을 그대로 재현하지 않는다.
- 참고 사이트의 코드, 사진, 로고, 스크린샷, 유료 서체를 앱 자산으로 사용하지 않았다. 확인용 스크린샷은 삭제했다.
- 서울 사진은 기존 로컬 자산 사용. 기존 출처/이용 조건 기록은 docs/romance-design.md 참조. 장소 검색 사진의 기존 출처/이용 조건과는 별개다.
- 독립 제작은 법적 비침해 보증을 의미하지 않는다. 참고 자료와 실제 구현을 구분해 기록한다.

## 검증
- check_editorial_design.py: 홈/저장 코스 결과 320·390·768·1440px, 가로 넘침 및 JS 오류 확인, 화면 저장.
- check_explore_navigation_ui.py: PC/모바일 장소 탐색·새로고침 복원·코스 입력으로 복귀.
- check_creator_ux_ui.py: 실제 장소 아이디어 선택 → 조건 반영 → 실제 코스 추천 → 추천 이유/옵션 → 1080x1350 PNG 저장, 후기 요약 3건, 모바일 가로 넘침/JS 오류 없음.
- check_photo_carousel_ui.py: 좌우/순환/키보드/스와이프, 배너 문구 대비.
- check_simple_form_ui.py: 필수 입력, 상세 옵션, 조건 적용 및 모바일 흐름.

시각 변경에 관한 검증이며 모든 외부 장소 데이터의 정확성이나 검색 공급자 응답을 보증하는 테스트는 아니다.
