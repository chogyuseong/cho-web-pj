# 참조 링크 주소 정리 (2026-10-23)
- 신규 장소 수집 시 지도 참조 URL은 기존 공통 place_query를 사용해 도로명 건물번호까지만 생성한다.
- 브라우저 링크 처리에서도 네이버 지도 검색 및 네이버 검색 query를 정리해 이미 저장된 일정/캐시의 층·호수·건물명이 붙은 링크에도 적용한다.
- 식당/레저 지도 버튼도 공통 검색어 처리. 실제 장소 주소 표시와 원본 블로그 게시물 URL은 유지한다.
- 화면 표시 문구의 '근거'는 '참조'로 통일한다. 내부 API 필드명/저장 데이터 구조는 유지.
- 예: 박흥권 탁구 클럽 서울특별시 강남구 선릉로 664 건설빌딩 지하1층 → 박흥권 탁구 클럽 서울특별시 강남구 선릉로 664.
- 검증: 주소/탐색/레저 API 테스트 14개 통과. 브라우저에서 지도/통합검색 URL, 표시 문구, 원본 블로그 링크 유지, 실제 링크 새 탭 이동 및 모바일 레저 교체/되돌리기 통과.
