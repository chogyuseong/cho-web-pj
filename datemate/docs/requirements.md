# 요구사항 정의 및 구현 대조표

기준: 사용자 첨부 요청, 2026-10-21. 과제 PDF와 AGENTS.md는 작업 폴더에서 발견되지 않음. 원본 PDF의 NF 번호/버전 및 상세 평가기준과 대조하지 않았음.

## 제품 범위

- 한국어, 서울 임시 지역 (`SERVICE_REGION` 설정), 최대 3개 추천, 장소 2~5개.
- 필수: 날짜·시간·인원·예산·교통·출발 좌표·구간 제한. 선택: 귀가·도보 제한.
- 선호/사용자 제약: 테마·실내외·피할 활동·예약 여부. UI에서 테마/실내외를 선택하면 제한으로 취급.
- MBTI는 끄기 가능, 명시 테마보다 후순위인 작은 설계 가중치. 과학적 효과를 주장하지 않음.
- 일정 비교, 상세, 고정/교체/되돌리기, 장소 자료·질문, 일정 질문, 공유 링크·인쇄, 자체 후기.
- UI에 데모 가정/추정/미확인과 실제 자료를 구분. 미확인 비용 0 처리 금지.
