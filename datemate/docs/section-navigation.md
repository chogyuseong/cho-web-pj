# 화면 간 섹션 이동 수정 (2026-10-23)
- 테마별 추천/장소 아이디어/코스 설계 앵커는 숨겨진 화면으로 바로 스크롤하지 않고 홈 입력 화면을 먼저 표시한 뒤 대상 영역으로 이동한다.
- 같은 해시 상태에서 반복 클릭도 처리. 해시 변경과 직접 접속/새로고침에서 테마·아이디어 섹션 복원 지원.
- 뒤로/앞으로 이동의 hashchange에서도 화면을 복원한다. 선택된 추천 데이터 자체는 삭제하지 않는다.
- 검증: 홈·장소 탐색·추천 결과에서 테마 이동, 반복 클릭, 새로고침, 테마 프리셋 적용, 탐색에서 코스 설계 CTA, PC·모바일 메뉴와 JS 오류 검사 통과.
