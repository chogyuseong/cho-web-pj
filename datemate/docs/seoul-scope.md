# 서울 전용 서비스 변경

- 브라우저 제목, 브랜드, Hero, 내비게이션, 검색 안내 및 footer를 서울 전용으로 변경했습니다.
- 추천 지역 입력은 서울 하나만 제공하며 자연어 조건 해석도 서울 지역을 유지합니다.
- 서버의 SERVICE_REGION 환경변수로 지역을 확장할 수 없도록 서울로 고정했습니다.
- 다른 지역의 일정 요청은 422로 거절합니다. 서울시·서울특별시 표기는 서울로 정규화합니다.
- 공통 카탈로그에서 서울 외 지역과 지역 미상 항목을 제외하므로 검색, 상세, 추천이 같은 범위를 사용합니다.
- 출발지와 귀가지는 이동의 기준점으로 서울 밖도 허용합니다. 추천 방문 장소는 서울로 제한하며 화면에도 이를 안내합니다.

지역 필터는 출처가 있는 메타데이터의 region을 기준으로 합니다. 서울 행정경계 폴리곤 판별 기능을 추가한 것은 아니므로, 원본의 지역 분류가 틀린 경우에는 자료 검수가 필요합니다.

검증: pytest tests -q 31개 통과, JavaScript 구문 검사 통과. Edge의 1440px·390px에서 제목, 지역 선택, 장소 탐색, 가로 넘침 없음 및 JavaScript 오류 없음을 확인했습니다. `/api/status`의 region=서울, temporary_region=false도 확인했습니다.

캡처: screenshots/seoul-home-1440.png, seoul-home-390.png, seoul-explore-1440.png, seoul-explore-390.png.
재검증은 로컬 서버를 8011번 포트에 실행한 뒤 `python scripts/check_seoul_ui.py`로 수행합니다.
