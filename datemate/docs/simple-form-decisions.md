# 맞춤 코스 입력 항목 축소 · 2026-10-23

## 조사와 우선순위

데이트 계획 관련 공개 검색 결과에서 조사 주체가 직접 발표한 자료를 확인했다. 아래 순서는 설문 하나에서 측정한 한국인 순위가 아니라, 조사 결과와 이 서비스의 코스 계산에 필요한 정보를 함께 고려한 제품 설계 판단이다.

| 우선순위 | 항목 | 판단 근거와 처리 |
|---|---|---|
| 1 | 지역 | 실제 방문 후보와 동선을 결정하는 기본 입력. 서울 지역명·주소·지도 선택으로 통합 |
| 2 | 날짜·시간 | 방문 가능 시간과 일정 길이를 계산하기 위한 필수 정보. 오늘·11~19시 기본값 유지 |
| 3 | 전체 예산 | 비용 부담을 고려하는 데이트 조사 결과를 반영. 2인 합계 10만원 기본값, 직접 변경 가능 |
| 4 | 원하는 활동 | 취향에 따른 장소 선택을 반영. 카페·맛집·산책·전시·체험 예시와 자유 입력 하나로 통합. 선택 사항 |
| 선택 | 인원·장소 수·이동·실내외·식사 | 기본 2인·3곳. 필요할 때만 펼쳐 변경 |

## 바뀐 화면

- 지역·일시·예산의 기본 묶음 3개, 선택 활동 묶음 1개만 우선 노출한다.
- 활동 입력 예시를 누르면 자유 요청에 추가한다. 동일 활동을 여러 검색창·테마·성향 기준으로 반복 입력할 필요가 없다.
- 인원·방문 수·교통수단·실내외·식사만 추가 설정에 남긴다.
- 데이터 모드, 서울 고정 선택, 별도 블로그 검색어, 성향·만남 분류, 자료 신뢰도, 필수 조건 선택, 상세 이동 제한, 귀가, MBTI, 체류 시간·추정 옵션 등의 조작 UI를 기본 입력에서 제거한다. API 및 기존 코스 데이터와의 호환을 위한 폼 기본값은 숨겨 보존한다.
- 비용은 추정이 포함될 수 있고 후보 부족 시 조건을 넓히며 변경 내용을 알린다는 안내를 유지한다.
- 실제 장소 모드에서 가상 ‘데모 출발점’을 기본 지역으로 보여주던 값을 없앴다. 지역은 직접 선택하며, 퀵가이드를 사용하면 선택한 지역이 적용된다.

## 검증

`scripts/check_simple_form_ui.py`로 필수 묶음·선택 설정·활동 예시 입력·기본값·인원/이동 변경값 전송·추천 생성·조건 수정·재검색·390px 가로 넘침·JavaScript 오류 여부를 점검했다. 테스트용 추천은 가상 장소로 서버 검증을 수행했다. 실제 지역 검색과 은평구 추천은 별도 브라우저 시나리오로 확인했다. 기존 퀵가이드 추천도 별도 점검했다. 실제 사용자 대상 사용성 실험이나 입력 시간 단축 수치 측정은 아직 하지 않았다.

카페투어 검증에서 넓은 ‘카페·미식’ 테마가 붙었다는 이유만으로 박물관을 카페로 판단하던 문제도 수정했다. 자유 입력 두 문구로 실제 카페 3곳 추천, 식사 포함 해제, 모바일 가로 넘침 없음, 페이지 오류 없음을 확인했다.
