# 지각 복구(대신 갈 곳·빼고 진행) — 설계 (2026-11-22, 짧은 설계, 메인 지시 기준)

## 왜
52차 '늦어지면 어디서 문제가 생길까?'(app/delay_check.py)는 읽기 전용이라, 늦어서 맞출 수 없게 된 장소를 알려 주기만 했다.
배포-이어가기.txt 7절 '개발로 남은 것'의 마지막 구조 분석 제안 '지각 복구(대체 장소)'를 채운다.

## 정한 것(메인 지시)
- 대상: 지각 확인의 첫 문제가 장소의 마지막 입장·영업 종료일 때 그 장소 하나. 축제 운영 시간·일정 종료 초과는 대상이 아니다.
- 후보: 코스를 만들 때 쓰던 동네 후보(장소 바꾸기 planner.replacements 와 같은 출처)에서만. 새 외부 호출 없음.
  같은 종류 = option_diversity.place_group(식사·카페·보기·걷기·하기·쉬기, '기타'면 같은 분류). 코스에 있는 곳·예약 필요·방문일 휴무 제외.
- 열림: 지연을 반영한 도착부터 머무는 동안 영업(planner.visit_window). 영업시간 모르는 후보는 맨 뒤 '영업시간 미확인'.
- 거리: 앞뒤 구간 ≤ max_leg, 이동이 덜 늘어나는 순 최대 3곳.
- 빼고 진행: 까닭 한 줄. 0곳이 되면 허용하지 않음.
- 저장: 장소 바꾸기처럼 새 코스 id(parent) — 되돌리기·이력 그대로. 시간표는 지연을 반영해 다시 계산.
- 충돌: 축제(맨 앞 고정·코스 끝) 시각을 못 맞추면 409. 예약 장소는 바꾸지 않고 '예약처에 연락' 안내. 실행 카드 체크 이어받기 유지.
- 공유 화면·편집 불가·보관 기한 지난 코스에는 단추 없음.

## 내가 정한 것(지시로 안 풀린 부분 — 보수적인 쪽)
1. **지연을 시간표에 넣는 법**: planner.evaluate 에 `delays={장소 번호: 분}`을 더해 그 장소 도착에 지연을 더하고 나머지는 같은 규칙으로 계산.
   (따로 시간표를 덮어쓰면 저녁 축제 배치·귀가·종료 판단이 evaluate 와 어긋난다.) evaluate 는 soft — 종료·예산·구간 초과로 실패하지 않게 하고,
   바뀐 것만 따로 거른다(아래 3).
2. **남은 일정 전체가 맞아야 후보**: 바꾼 뒤에도 뒤 장소가 또 늦으면 그 후보는 내지 않는다(그런 코스는 저장하지 않음). 모두 막히면 까닭('뒤 C 에서 영업 종료…')을 적고,
   빼고 진행이 맞으면 그것만 남는다. 여러 장소를 한 번에 바꾸지는 않는다.
3. **거르는 것**: 축제 배치가 달라짐(코스 끝 축제가 빠짐·맨 앞 축제 시각이 바뀜·없던 축제가 생김), 바뀐 앞뒤 구간 > max_leg, 예산·총 도보가 새로 넘침,
   꼭 지킬 조건(hard_constraints)이 새로 깨짐. 일정 종료 초과는 막지 않고 알린다(지각 때문이라 장소를 바꿔 풀 수 없다).
4. **고정한 장소**는 바꾸지도 빼지도 않는다(장소 바꾸기와 같은 규칙). **방문 장소 수(count)** 는 빼도 사용자가 정한 값 그대로(조건 확인에 '요청 3곳, 2곳').
5. **길찾기**: 바뀌지 않은 구간은 저장값 그대로(routes.saved_routes), 새 구간은 직선거리 추정. 자동차 코스도 길찾기를 새로 부르지 않는다
   (장소 바꾸기는 다시 조회하지만 이 기능은 '새 외부 호출 없음'을 따름). 그런 코스는 저장 뒤 '추정' 안내.
6. **저장 기록**: plan['delay_recovery'] = {delays, index, target, action, place, replacement}. 지각 확인을 다시 열면 그 장소의 도착 예정에 반영한 지연을 더해
   '지금 시간표' 기준으로 본다(delay_check.carried_delay). 다른 변경(수단·장소 바꾸기 등)은 시간표를 지연 없이 다시 짜므로 save_change 가 기록을 지운다.
7. **데모 코스**: 가상 장소 목록도 '이미 있는 후보'라 숨기지 않는다. 대개 영업시간이 같아 '대체 후보 없음'이 나온다.

## 하지 않는 것
여러 장소 한꺼번에 바꾸기, 순서 바꾸기, 새 장소 검색·길찾기, 공유 화면에 싣기, 수단 바꾸기 뒤에도 지연 유지.
