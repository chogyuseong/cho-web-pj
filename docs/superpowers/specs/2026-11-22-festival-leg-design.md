# 저녁 축제 돌아오는 구간: 지도 선과 수단 바꾸기 — 설계 (2026-11-22, 짧은 설계, 사용자 승인)

## 왜
70차(저녁 축제를 코스 끝에)에서 '마지막 장소 → 행사장' 구간은 plan['legs'] 밖(festival_visit.leg)에 두었다. 그래서
① 지도(네이버·공개 지도·개략도)가 출발지·장소·귀가지를 차례로 이어, 귀가를 고르면 귀가 선이 마지막 장소에서 나간다(실제는 행사장에서 출발 — 버그),
② 이 구간의 수단을 바꿀 수 없다.

## 정한 것
- 지도: 구간 목록을 한 함수(maps.js planSegments)로 만든다 — 장소 도착 구간들, 저녁 축제면 '마지막 장소 → 행사장(출발지 좌표)'(festival_visit.leg),
  귀가면 '행사장 또는 마지막 장소 → 귀가지'. 세 지도 모두 이 목록으로 선을 그린다. 돌아오는 구간은 경로 모양을 저장하지 않아 점선만.
- 수단 바꾸기: /api/plans/{id}/transport 요청에 `festival`(수단) 항목을 더한다(방법 가). 구간 번호 체계(legs index)는 그대로.
  수단 예외 키는 planner 가 이미 읽는 (마지막 장소 id, 'festival'). next_leg_modes 가 이 키를 '지금 코스의 구간'으로 인정해 다른 구간을 바꿔도 남는다.
  저녁 축제가 없는 코스에 festival 을 보내면 422. 같은 수단이면 '이미 그 이동 수단이에요'.
- 화면: 코스 상세 축제 칸의 '마지막 장소 → 축제 행사장' 줄에 [수단 바꾸기].
- 하지 않는 것: 축제를 코스 중간에 두기, 돌아오는 구간의 실제 도로 경로 저장, 공유 화면 변경.

## 방법
가(선택) 요청에 축제 구간 항목 추가 / 나 구간 번호에 특수 번호 — 기존 번호 규칙과 섞임 / 다 돌아오는 구간을 legs 에 넣기 — 70차에서 20여 곳 깨짐을 피하려 하지 않은 방법.
